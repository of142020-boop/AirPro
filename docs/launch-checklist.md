# تجهيز إطلاق AirPro

الموقع تحت الإنشاء، ولا يوجد دومين نهائي مؤكد. يحتفظ برقم التواصل الموجود في المشروع: 01101219418. لم يُنشر أو تُضاف روابط تبادل بين المواقع.

## إعدادات البناء

- الافتراضي: جميع الصفحات noindex,follow؛ خريطة الموقع فارغة. robots يسمح بالزحف حتى يستطيع محرك البحث قراءة noindex. هذا لا يمنع وصول الناس للموقع؛ استخدم حماية وصول في الاستضافة إذا كانت المعاينة خاصة.
- SITE_URL: أصل HTTPS النهائي فقط، مثل https://YOUR-REAL-DOMAIN، دون مسار. يضبط Canonical وعنوان المشاركة وروابط الخريطة.
- SITE_LAUNCH_READY=true: يُفعل الفهرسة فقط بعد تأكيد الدومين واستعداد الموقع. البناء يفشل إذا فُعّل دون SITE_URL.
- إعدادات المنصة متغيرات بيئة وقت البناء؛ لا تحتاج وضع أسرار في المتصفح. اضبطها قبل البناء وأعد البناء عند تغييرها.
- صفحة الأعمال تبقى noindex وتُستثنى من الخريطة حتى توفير أعمال حقيقية ومراجعة محتواها وإزالة noindex صراحةً.

## ما أُصلح

إزالة الخط الساخن المختصر 19418 واستعمال رقم المشروع الكامل؛ نموذج واتساب حقيقي دون رسالة نجاح وهمية؛ روابط الحجز والخصوصية والشروط؛ قائمة هاتف قابلة للتشغيل بلوحة المفاتيح؛ حذف مراجع صور الخدمات غير الموجودة؛ إزالة عرض صور عامة كأعمال حقيقية والوكالات والاعتمادات وأرقام الخبرة غير الموثقة؛ محتوى مستقل لكل خدمة وروابط داخلية؛ وصف وعنوان ومحتوى رئيسي فريد؛ Canonical مشروط بدومين مؤكد؛ Open Graph وTwitter؛ بيانات WebPage عند وجود الدومين دون اختراع عنوان تجاري أو تقييمات.

## مطلوب قبل الإطلاق

1. تأكيد الدومين النهائي وملكية رقم التواصل والتغطية والخدمات المتاحة فعلياً.
2. مراجعة مواصفات الخدمات التجارية مع المسؤول عن تنفيذها، وأي شروط ضمان أو اعتمادات مدعاة قبل إضافتها.
3. إضافة أعمال وصور حقيقية بإذن أصحابها لاحقاً؛ لا توجد أسعار أو تقييمات مختلقة.
4. ضبط متغيرات الإطلاق، ثم npm run build وnpm run seo:check. البناء الافتراضي يبقى مسودة.
5. مراجعة الدومين الحي وHTTPS والتحويل إلى نسخة واحدة، ثم إثبات الملكية في Search Console وإرسال /sitemap.xml.
6. مراجعة أي تحليلات أو نماذج جديدة وتحديث الخصوصية لتطابق الخدمات الفعلية. لا يوجد backend يستقبل نموذج الحجز؛ يجهز رابط واتساب ويراجع المستخدم الرسالة ويرسلها بنفسه.
